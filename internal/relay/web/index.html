连接你的电脑

两端主动连接中转站，不需要开放电脑的入站端口。

第一次连接

  1. 点击「添加设备」，下载这台电脑的 client.json。
  2. 无需填写项目路径；客户端自动发现 Codex 和 Claude Code 的历史项目。
  3. 运行 relay client --config client.json，项目列表约每分钟自动刷新。
  4. 另一台电脑独有的项目，恢复时选择「在本机新建项目」。项目代码请自行同步。
